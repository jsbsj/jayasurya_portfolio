# NHS ERIC 2024/25 — Business Analysis & Power BI

An independent BA case study demonstrating:

**Business problem → evidence → analysis → findings → requirements → process → solution → testing → expected value**

## Evidence
- `case-study.pdf` — recruiter-facing case study
- `sql/` — business-question-led SQL investigation
- `requirements/` — requirements and traceability
- `process/` — AS-IS and TO-BE process summaries
- `power-bi/` — Power BI MVP rationale
- `testing/` — technical testing and UAT summary
- `delivery/` — benefits, risks and governance

## Evidence boundaries
This is independent portfolio work using publicly available NHS England data. It is not an NHS implementation, does not claim NHS stakeholder engagement, and does not claim realised benefits or production deployment.
